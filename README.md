# رفيق الصلاة — الموقع الرسمي

موقع تعريفي عربي لتطبيق رفيق الصلاة، بتصميم متجاوب يدعم الهاتف والكمبيوتر.

## الصفحات
- `index.html`: الصفحة الرئيسية ومعلومات التطبيق والدعم الفني.
- `privacy.html`: سياسة الخصوصية.
- `favicon.svg`: أيقونة الموقع.

## النشر المجاني
يستخدم GitHub Actions لنشر محتويات المستودع عبر GitHub Pages. افتح **Settings → Pages** واجعل **Build and deployment → Source** هو **GitHub Actions** إذا لم يُفعّل تلقائيًا. ثم راقب تبويب **Actions**.
